你是一名 微信小程序 工程师。我正在开发一款潮汐类小程序。请按以下规格实现功能，并确保项目可编译运行。

开发约束
- 代码尽量简单易读
- 不使用任何第三方库

交付要求
- 完成实现后，请输出「本次改动日志」（新增/修改了哪些内容、涉及哪些页面/文件）

信息架构
- 底部 Tab 必须包含 4 个页面：
  1) 睡眠（Sleep）
  2) 专注（Focus）
  3) 呼吸（Breathe）
  4) 冥想（Meditate）

数据源（必须接入，请避免网络缓存）
- API：https://zzz-pet.oss-cn-hangzhou.aliyuncs.com/api/sounds.json
- 返回格式：
{
  "alarm": {
    "id": "morning_joy",
    "name": "Morning Joy",
    "url": "https://xxxx.mp3",
    "cover": ""
  },
  "sounds": [
    {
      "id": "cat_purr_1",
      "name": "猫呼噜声",
      "url": "https://xxx.m4a",
      "cover": "https://xxx.jpg"
    }
  ]
}
- 数据使用规则：
  - 「睡眠」与「专注」共用同一份 sounds
  - 「睡眠」闹钟音乐使用 alarm

全局通用体验要求
- 网络加载必须包含：加载中 / 失败提示 + 失败重试
- 图片严格与显示区域一致；所有封面图都“填充裁剪”为 1:1
- 音频在切换页面时不要莫名停止（除非用户主动停止）


功能需求

A) 睡眠（Sleep）
1) 声音列表
- 使用两列网格展示 sounds
- 卡片展示：封面图+ 名称文字叠在封面中心
- 点击任意卡片进入播放页

2) 播放页
- 页面展示：封面+ 名称 + 播放/暂停按钮
- 白噪音循环播放

3) 睡眠定时（按“醒来时间”）
- 用户选择“醒来时间”后开始倒计时，并显示剩余时间
- 到点后：
  - 自动停止白噪音
  - 弹窗提示：“该起床了”
  - 同时播放 alarm（循环播放，最多 20 分钟）
  - 弹窗只有一个按钮：“停止闹钟”
    - 点击后立即停止闹钟并结束流程
  - 若用户未点击停止，20 分钟到也要自动停止并结束流程
- 规则：若选择的醒来时间已过，默认视为“明天同一时间”

B) 专注（Focus）
1) 番茄钟
- 提供两套模式：25/5、50/10（专注/休息）
- 页面展示：当前阶段（专注/休息）、剩余时间、开始/暂停/结束按钮

2) 背景音
- 可选择一个 sounds 作为专注背景音
- 开始时自动播放；暂停/结束时停止

3) 沉浸模式（简单版）
- 提供沉浸模式开关
- 开启后：专注期间若 App 进入后台，判定本次失败并提示，同时停止计时与声音

C) 呼吸（Breathe）
1) 练习入口（每个入口包含“适用场景”说明）
- 4-4-4-4（吸4 屏4 呼4 屏4 循环）：适合紧张、焦虑、需要快速冷静/稳住情绪
- 4-7-8（吸4 屏7 呼8 循环）：适合睡前放松、帮助更快入眠
- 5-5（吸5 呼5 循环）：适合日常减压、恢复平静与专注（随时可做）

2) 训练页（共用一个训练页面）
- 显示：当前阶段（吸气/屏息/呼气）
- 显示圆球：圆球内显示倒计时秒数
- 圆球动画：
  - 吸气：随时间变大
  - 屏息：不变
  - 呼气：随时间变小
- 操作按钮：开始 / 暂停 / 结束
- 显示：本次训练已进行时长（从开始累计）

D) 冥想（Meditate）
1) 列表（静态数据即可）
- 4 条：快速入眠 / 考试压力 / 呼吸练习 / 身体扫描
- 列表展示要清晰（标题 + 一句简介即可）

2) 详情页
- 标题 + 简介 + “开始”按钮

3) 引导页（最简）
- 进入后按段落展示引导文字（例如 4-6 段即可）
- 提供：下一段 / 上一段 / 结束
- 点击结束：返回冥想详情页或列表页（保持流程简单一致）
